# Product Inventory System

A full-stack Product Inventory Management System built using React (Frontend), FastAPI (Backend), and PostgreSQL (Database).

---

## Features

* Add, update, and delete digital products
* Track product quantity, price, name, description, and ID
* Clean and simple UI using React
* Fast and efficient backend using FastAPI
* Persistent data storage with PostgreSQL

---

## Tech Stack

* Frontend: React
* Backend: FastAPI
* Database: PostgreSQL
* Other Tools: REST APIs, JSON

---

## How to Run the Project

### Backend (FastAPI)

1. Create virtual environment:

```
python -m venv myenv
```

2. Activate it:

```
myenv\Scripts\activate
```

3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run server:

```
uvicorn main:app --reload
```

---

### Frontend (React)

1. Go to frontend folder:

```
cd frontend
```

2. Install dependencies:

```
npm install
```

3. Start React app:

```
npm start
```
